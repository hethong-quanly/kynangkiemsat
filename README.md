# Quy trinh nghiep vu kiem sat — VKSND TP Can Tho

Trang cong khai: https://hethong-quanly.github.io/quytrinhkiemsat/

Nhom IT — Vien Kiem sat nhan dan thanh pho Can Tho

## Cau truc

- `index.html` — trang chu (logo → bang cong cu → mo tool trong khung)
- `AnDanh/` — an danh van ban ngay tren trinh duyet (`index.html` + `andanh.js`), kem `AnDanhTool.zip` cho Windows
- `Data/` — tinh tuoi/thoi han, huong dan so do tu duy
- `Tool/` — lai suat, an phi, doi ten file, docx→md, OCR PDF
- `static/` — logo va tai nguyen

The **Tu dong che thong tin** tro toi `AnDanh/index.html`. File khong roi may nguoi dung.
